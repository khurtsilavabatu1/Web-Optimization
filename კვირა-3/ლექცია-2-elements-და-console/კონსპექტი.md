# ლექცია 2 — Chrome DevTools: Elements და Console

## 2.1 Elements Panel

- **რას აკეთებს:** HTML/CSS-ის real-time ინსპექტირება და რედაქტირება

### გამოყენება:
- **Cmd+Shift+C** — ელემენტის სწრაფი არჩევა (inspect)
- DOM სტრუქტურის ნახვა და real-time რედაქტირება
- CSS სტილების ცვლილება (სტილი მაშინვე ჩანს)
- **Computed tab** — ფინალური გამოთვლილი სტილები
- **Box Model** — margin, border, padding ვიზუალიზაცია
- **Force Element State** — :hover, :focus, :active სიმულაცია
- **Break on...** — DOM ცვლილებაზე breakpoint

## 2.2 Console Panel

### Console API — ძირითადი:
```javascript
console.log('ინფორმაცია');
console.warn('გაფრთხილება');       // ყვითელი
console.error('შეცდომა');          // წითელი
```

### Console API — მოწინავე:
```javascript
// ცხრილის სახით
console.table([
  { name: 'Alice', age: 25 },
  { name: 'Bob', age: 30 },
]);

// დაჯგუფება
console.group('User Data');
console.log('Name: Alice');
console.log('Age: 25');
console.groupEnd();

// დროის გაზომვა
console.time('API call');
await fetch('/api/data');
console.timeEnd('API call');
// API call: 234.5ms

// პირობითი logging
console.assert(value > 0, 'Value must be positive!', value);

// სტილიზაცია
console.log('%cSuccess!', 'color: green; font-size: 20px; font-weight: bold');

// Stack trace
console.trace('Where was this called from?');

// counter (render-ების დათვლა და ა.შ.)
console.count('render');  // render: 1
console.count('render');  // render: 2
```

### Console Shortcuts:
```javascript
// $0 — Elements panel-ში არჩეული ელემენტი
$0.textContent

// $('selector') — querySelector
$('.header')

// $$('selector') — querySelectorAll (როგორც Array)
$$('img').map(img => img.src)

// copy() — clipboard-ში კოპირება
copy(JSON.stringify(data, null, 2))

// monitor() — ფუნქციის გამოძახების მონიტორინგი
monitor(myFunction)
```
