# Habit Tracker — Debugging დავალების პროექტი

**კვირა 3, ლექცია 1 — Debugging-ის კონცეფცია**

ეს არის დავალების პროექტი Vite + React-ზე. აპლიკაცია **6 განზრახ ჩადებულ React-ის შეცდომას** შეიცავს — თითოეული იმ ტიპისაა, რაც ლექციის გაიდში (`GUIDE.md`) განვიხილეთ, მაგრამ **სხვა კოდში და სხვა ადგილას**.

> კოდში `// BUG #N` კომენტარები **არ არის** — ბაგები თავად უნდა იპოვოთ.

## 🚀 გაშვება

```bash
npm install
npm run dev
```

ბრაუზერში: `http://localhost:5173`

## 🧩 რას აკეთებს აპლიკაცია

ჩვევების ტრეკერი:

- ჩვევის დამატება სათაურით და კატეგორიით (ჯანმრთელობა / სწავლა / პროდუქტიულობა)
- დღევანდელი შესრულების მონიშვნა checkbox-ით (streak 🔥 იზრდება)
- ფილტრაცია: ყველა / შესასრულებელი / შესრულებული
- თითოეულ ჩვევაზე შენიშვნის ჩაწერა
- წაშლა და „5 წამში წაშლა" (გადაფიქრების დრო)
- „ბოლო დამატებიდან" მთვლელი badge

## 🐛 შეცდომები

აპლიკაციის მარჯვენა პანელში **6 სიმპტომია** აღწერილი — მიზეზი, ფაილი და ხაზი დავალების ნაწილია.

დეტალური ინსტრუქცია და ჩასაბარებელი მასალები: `../README.md`

## 📁 სტრუქტურა

```
src/
  App.jsx                      → banner + სიმპტომების პანელი
  App.css
  components/
    HabitTracker.jsx           → state, დამატება/წაშლა/ფილტრაცია
    HabitForm.jsx              → ჩვევის დამატების ფორმა
    HabitList.jsx              → ჩვევების სია
    HabitCard.jsx              → ერთი ჩვევის ბარათი
    StreakBadge.jsx            → „ბოლო დამატებიდან" მთვლელი
```

## 🔧 ინსტრუმენტები

- **Console** — შეცდომები, warning-ები, `console.log`
- **React DevTools** → Components — props და state რეალურ დროში
- **Sources** → breakpoint-ები, Scope, Call Stack
- **Performance / Memory** — interval-ების და memory leak-ის შესამოწმებლად
