# დავალება: Debugging-ის კონცეფცია — Habit Tracker

**ლექცია:** კვირა 3, ლექცია 1
**პროექტი:** `homework-debugging/`
**შესრულების დრო:** ~2-3 საათი (დამოუკიდებლად)

---

## აღწერა

მოცემულია **Habit Tracker** — React აპლიკაცია ჩვევების თვალყურის დევნებისთვის. აპი გარეგნულად მუშაობს, მაგრამ შიგნით **6 React-სპეციფიკური ბაგია** ჩადებული — იგივე ტიპის, რაც ლექციის გაიდში (`../GUIDE.md`) `demo-debugging` პროექტზე განვიხილეთ, ოღონდ **სხვა კოდში, სხვა კომპონენტებში და სხვა სიმპტომებით**.

განსხვავება ლექციის პროექტისგან:

- კოდში `// BUG #N` კომენტარები **არ არის**
- აპლიკაციის პანელი მხოლოდ **სიმპტომს** აღწერს — მიზეზს, ფაილს და ხაზს **თქვენ პოულობთ**
- ბაგის ტიპის დასახელებაც (Runtime / Logic და კონკრეტული React-ის კატეგორია) დავალების ნაწილია

**შენი ამოცანა:** იპოვე 6-ვე ბაგი, დაასახელე მისი ტიპი და მიზეზი, გამოასწორე და დაადასტურე შედეგი.
