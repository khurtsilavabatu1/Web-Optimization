# ლექცია 1 — Debugging-ის კონცეფცია და შეცდომების ტიპები

## 1.1 რა არის Debugging?

Debugging (გამართვა) არის პროგრამულ კოდში შეცდომების (bugs) აღმოჩენისა და გამოსწორების პროცესი.

### Debugging-ის მიდგომები:

**1. Scientific Method (სისტემატური):**
1. **დააკვირდი** — რა ხდება? რა უნდა ხდებოდეს?
2. **ჩამოაყალიბე ჰიპოთეზა** — რატომ ხდება ეს?
3. **შეამოწმე** — ექსპერიმენტით დაადასტურე ან უარყავი
4. **გამოასწორე** — შეცვალე კოდი
5. **გადაამოწმე** — შეცდომა აღარ მეორდება?

**2. Rubber Duck Debugging:**
ახსენი პრობლემა ხმამაღლა — ხშირად ახსნის პროცესშივე აღმოაჩენ შეცდომას.

**3. Binary Search (Bisecting):**
კოდის ნახევარი გამორთე → მუშაობს? → მეორე ნახევარში ეძებე. თითოეულ ნაბიჯზე ნახევრდება საძიებო არე.

**4. Elimination:**
გამორიცხე ფაქტორები სათითაოდ: ქსელი? მონაცემები? State? UI?

## 1.2 სინტაქსის შეცდომები (Syntax Errors)

კოდი არ ეთანხმება ენის წესებს — არ კომპილირდება/შესრულდება.

```javascript
// ❌ გამოტოვებული ფრჩხილი
function greet(name {
  return `Hello, ${name}`;
}
// SyntaxError: Unexpected token '{'

// ❌ გამოტოვებული მძიმე
const items = [1, 2 3];
// SyntaxError: Unexpected number

// ❌ Reserved keyword ცვლადის სახელად
const class = 'math';
// SyntaxError: Unexpected token 'class'

// ❌ არასწორი JSON
JSON.parse("{'key': 'value'}");
// SyntaxError: Unexpected token "'"
```

**როგორ ვიპოვოთ:** ESLint, TypeScript, ბრაუზერის console

## 1.3 შესრულების შეცდომები (Runtime Errors)

სინტაქსურად სწორი, მაგრამ შესრულების დროს იშლება.

```javascript
// ❌ TypeError — undefined/null-ზე method
const user = null;
console.log(user.name);
// TypeError: Cannot read properties of null (reading 'name')

// ❌ ReferenceError — არარსებული ცვლადი
console.log(undeclaredVariable);
// ReferenceError: undeclaredVariable is not defined

// ❌ TypeError — არაფუნქციის გამოძახება
const number = 42;
number();
// TypeError: number is not a function

// ❌ RangeError — stack overflow
function infinite() { infinite(); }
infinite();
// RangeError: Maximum call stack size exceeded
```

**როგორ ავიცილოთ:**
```javascript
// Optional chaining
const name = user?.name;
const city = user?.address?.city;

// Nullish coalescing
const displayName = user?.name ?? 'Unknown';

// Default parameters
function greet(name = 'Guest') {
  return `Hello, ${name}`;
}
```

## 1.4 ლოგიკური შეცდომები (Logic Errors)

ყველაზე რთული — კოდი მუშაობს, მაგრამ არასწორ შედეგს იძლევა.

```javascript
// ❌ Off-by-one error
function getLastItem(array) {
  return array[array.length]; // უნდა იყოს array.length - 1
}

// ❌ == ნაცვლად ===
if (userInput == 0) { /* "0" string-იც გაივლის */ }

// ❌ State mutation React-ში
function addItem(items, newItem) {
  items.push(newItem); // ❌ მუტაცია — React ვერ დაინახავს ცვლილებას
  return items;
}
// ✅ ახალი მასივი
function addItem(items, newItem) {
  return [...items, newItem];
}

// ❌ Stale closure React-ში
useEffect(() => {
  const interval = setInterval(() => {
    setCount(count + 1); // ❌ count ყოველთვის 0-ია (stale closure)
  }, 1000);
  return () => clearInterval(interval);
}, []);
// ✅ setCount(prev => prev + 1);
```

## სავარჯიშო

თითოეულ ფუნქციაში იპოვეთ შეცდომა, დაასახელეთ ტიპი, გამოასწორეთ:

```javascript
// 1.
function findAverage(numbers) {
  let sum = 0;
  for (let i = 1; i <= numbers.length; i++) {
    sum += numbers[i];
  }
  return sum / numbers.length;
}
// Test: findAverage([10, 20, 30]) → 20 (დააბრუნებს NaN — რატომ?)

// 2.
function filterByPrice(products, minPrice, maxPrice) {
  return products.filter(product => {
    product.price >= minPrice && product.price <= maxPrice;
  });
}
// Test: filterByPrice([{price:10},{price:50}], 5, 30) → [{price:10}] (დააბრუნებს [] — რატომ?)

// 3.
async function fetchUserData(userId) {
  const response = fetch(`https://jsonplaceholder.typicode.com/users/${userId}`);
  const data = response.json();
  return data;
}
// Test: fetchUserData(1) → user object (error — რატომ?)
```
