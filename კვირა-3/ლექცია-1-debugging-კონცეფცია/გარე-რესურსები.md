# გარე რესურსები — ლექცია 1: Debugging-ის კონცეფცია

## Debugging — ზოგადი და მეთოდოლოგია

- [Debug JavaScript (Chrome DevTools)](https://developer.chrome.com/docs/devtools/javascript) — ოფიციალური შესავალი გზამკვლევი: სად დავიწყოთ debugging
- [Debugging in the browser (javascript.info)](https://javascript.info/debugging-chrome) — ბრაუზერში debugging-ის საფუძვლები ილუსტრაციებით
- [Rubber duck debugging](https://en.wikipedia.org/wiki/Rubber_duck_debugging) — „იხვისთვის ხმამაღლა ახსნის" მეთოდი
- [What went wrong? Troubleshooting JavaScript (MDN)](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting/What_went_wrong) — შეცდომების პოვნის მეთოდური მიდგომა დამწყებთათვის

## შეცდომების ტიპები

- [JavaScript error reference (MDN)](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Errors) — ყველა JS შეცდომის სრული ცნობარი ახსნებით
- [TypeError (MDN)](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/TypeError) — ყველაზე ხშირი Runtime შეცდომა
- [ReferenceError (MDN)](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/ReferenceError) — არარსებულ ცვლადზე მიმართვა
- [SyntaxError (MDN)](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/SyntaxError) — სინტაქსური შეცდომები
- [Error.cause (MDN)](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Error/cause) — შეცდომის მიზეზის ჯაჭვის შენარჩუნება

## Console

- [Console API reference (Chrome)](https://developer.chrome.com/docs/devtools/console/api) — `console`-ის ყველა მეთოდი: `table`, `group`, `count`, `time`, `trace`
- [Console utilities API (Chrome)](https://developer.chrome.com/docs/devtools/console/utilities) — `$0`, `$_`, `monitorEvents`, `copy` და სხვა DevTools-ის ხრიკები
- [console (MDN)](https://developer.mozilla.org/en-US/docs/Web/API/console) — `console`-ის ობიექტის დოკუმენტაცია
- [Format and style messages in the Console (Chrome)](https://developer.chrome.com/docs/devtools/console/format-style) — ლოგების ფორმატირება და სტილიზება

## Breakpoint-ები და Sources (შესავალი)

- [Pause your code with breakpoints (Chrome)](https://developer.chrome.com/docs/devtools/javascript/breakpoints) — breakpoint-ების ტიპები (დეტალურად ლექცია 4-ში)
- [debugger statement (MDN)](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/debugger) — `debugger;` პირდაპირ კოდიდან შეჩერება
- [DevTools keyboard shortcuts (Chrome)](https://developer.chrome.com/docs/devtools/shortcuts) — კლავიატურის მალსახმობების სრული სია

## React Debugging

- [React Developer Tools (react.dev)](https://react.dev/learn/react-developer-tools) — React DevTools-ის ინსტალაცია და გამოყენება
- [Components and Hooks must be pure (react.dev)](https://react.dev/reference/rules/components-and-hooks-must-be-pure) — რატომ არ შეიძლება state-ის მუტაცია და side effect-ები რენდერში
- [StrictMode (react.dev)](https://react.dev/reference/react/StrictMode) — რატომ სრულდება effect-ები ორჯერ development-ში

### State და მუტაცია

- [Updating Objects in State (react.dev)](https://react.dev/learn/updating-objects-in-state) — immutable განახლება ობიექტებზე
- [Updating Arrays in State (react.dev)](https://react.dev/learn/updating-arrays-in-state) — მასივების სწორი განახლება (`map`, `filter`, spread)
- [Queueing a Series of State Updates (react.dev)](https://react.dev/learn/queueing-a-series-of-state-updates) — updater ფუნქცია (`setX(prev => ...)`) და batching
- [useState (react.dev)](https://react.dev/reference/react/useState) — `useState`-ის სრული ცნობარი

### useEffect, cleanup და dependency-ები

- [Synchronizing with Effects (react.dev)](https://react.dev/learn/synchronizing-with-effects) — effect-ის სასიცოცხლო ციკლი და cleanup ფუნქცია
- [useEffect (react.dev)](https://react.dev/reference/react/useEffect) — API ცნობარი და ტიპური შეცდომები
- [Removing Effect Dependencies (react.dev)](https://react.dev/learn/removing-effect-dependencies) — dependency array-ის სწორად შედგენა
- [You Might Not Need an Effect (react.dev)](https://react.dev/learn/you-might-not-need-an-effect) — როდის არ გვჭირდება effect (derived state)
- [A Complete Guide to useEffect (Dan Abramov)](https://overreacted.io/a-complete-guide-to-useeffect/) — ვრცელი სტატია effect-ების მენტალურ მოდელზე
- [Making setInterval Declarative with React Hooks (Dan Abramov)](https://overreacted.io/making-setinterval-declarative-with-react-hooks/) — `setInterval` + hooks კლასიკური პრობლემა

### Closure და stale state

- [Closures (MDN)](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Closures) — closure-ის ცნება JavaScript-ში
- [Closure (javascript.info)](https://javascript.info/closure) — closure-ის დეტალური განმარტება მაგალითებით

### Key prop და სიები

- [Rendering Lists (react.dev)](https://react.dev/learn/rendering-lists) — `key`-ის წესები და რატომ არ ვიყენებთ index-ს
- [Preserving and Resetting State (react.dev)](https://react.dev/learn/preserving-and-resetting-state) — როგორ იმახსოვრებს React state-ს პოზიციისა და key-ის მიხედვით
