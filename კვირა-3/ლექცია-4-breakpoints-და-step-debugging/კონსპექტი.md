# ლექცია 4 — Breakpoints და Step Debugging + პრაქტიკა

## 4.1 Breakpoints — ტიპები

### Line-of-Code Breakpoints:
```
Sources panel → ფაილის გახსნა → ხაზის ნომერზე click
```

### Conditional Breakpoints:
```
ხაზის ნომერზე Right-click → "Add conditional breakpoint"
პირობა: userId === 42
```

### Logpoints (console.log-ის ნაცვლად):
```
Right-click → "Add logpoint"
შეტყობინება: 'User:', user.name, 'Items:', items.length
```

### DOM Breakpoints:
```
Elements → ელემენტზე Right-click → Break on:
- Subtree modifications
- Attribute modifications
- Node removal
```

### Event Listener Breakpoints:
```
Sources → Event Listener Breakpoints:
- Mouse → click
- Keyboard → keydown
- XHR/fetch → URL pattern
```

### Exception Breakpoints:
```
Sources → ⏸ ღილაკი
- Pause on caught exceptions
- Pause on uncaught exceptions
```

## 4.2 Step-by-Step Debugging

### Debugger Controls:
```
▶ Resume (F8)           — გაგრძელება შემდეგ breakpoint-მდე
⏭ Step Over (F10)       — შემდეგ ხაზზე (ფუნქციაში არ შედის)
⏬ Step Into (F11)       — ფუნქციაში შესვლა
⏫ Step Out (Shift+F11)  — ფუნქციიდან გამოსვლა
```

### Scope Panel:
- **Local** — ლოკალური ცვლადები
- **Closure** — closure-ში ხელმისაწვდომი
- **Global** — გლობალური scope

### Watch Expressions:
```
+ Add watch expression:
- user.name
- items.length
- items.filter(i => i.active).length
```

### Call Stack:
ფუნქციების გამოძახების ჯაჭვი — საიდან მოხვდა ამ წერტილში.

## სავარჯიშო (პრაქტიკა)

### Debugging Challenge
(იხილეთ პრაქტიკული-პროექტები/პროექტი-2-debugging-challenge.md — TodoList ნაწილი)

მოკლე ვერსია ლექციაზე:
```javascript
// ეს კოდი 3 ბაგს შეიცავს — Breakpoints-ით იპოვეთ
function processCart(items) {
  let total = 0;
  for (let i = 0; i <= items.length; i++) {
    total += items[i].price * items[i].quantity;
  }
  
  // ფასდაკლება 10%
  const discount = 10;
  const finalPrice = total - discount; // ❌ discount არის %, არა თანხა
  
  return finalPrice;
}

const cart = [
  { name: 'Laptop', price: 999.99, quantity: 1 },
  { name: 'Mouse', price: 29.99, quantity: 2 },
];

console.log(processCart(cart));
```

1. დადეთ breakpoint for loop-ის შიგნით
2. Step-by-step — Watch-ში: `i`, `items[i]`, `total`
3. იპოვეთ სამივე ბაგი
4. გამოასწორეთ და გადაამოწმეთ
