# Split the Bill — Breakpoints დავალების პროექტი

**კვირა 3, ლექცია 4 — Breakpoints და Step Debugging**

ეს არის დავალების პროექტი Vite + React-ზე. აპლიკაცია **5 განზრახ ჩადებულ შეცდომას** შეიცავს და თითოეული ისე შერჩეულია, რომ **კონკრეტული breakpoint-ის ტიპით** მოიძებნოს (line-of-code, step over/into, logpoint, exception, conditional + watch).

> კოდში `// BUG #N` კომენტარები **არ არის** — ბაგები თავად უნდა იპოვოთ.

## 🚀 გაშვება

```bash
npm install
npm run dev
```

ბრაუზერში: `http://localhost:5173`

## 🧩 რას აკეთებს აპლიკაცია

რესტორნის ანგარიშის კალკულატორი:

- მენიუდან კერძის დამატება ანგარიშში (რაოდენობის არჩევით)
- ანგარიშში რაოდენობის ცვლილება და კერძის წაშლა
- მომსახურების საფასური (10% / 15% / 20%)
- ჯამი და „თითო ადამიანზე" გაყოფა
- ანგარიშის დახურვა (სიმულირებული async API call)

## 🐛 შეცდომები

გვერდის ბოლოს **სიმპტომების პანელია** — 5 ბაგის სიმპტომი და გამეორების ნაბიჯები. მიზეზი, ფაილი და ხაზი დავალების ნაწილია.

დეტალური ინსტრუქცია და ჩასაბარებელი მასალები: `../README.md`

## 📁 სტრუქტურა

```
src/
  App.jsx                      → state და handler-ები
  App.css
  utils/
    billing.js                 → ყველა გამოთვლა (subtotal, მომსახურება, ჯამი, გაყოფა)
  components/
    MenuList.jsx               → მენიუს სია
    MenuCard.jsx               → კერძის ბარათი + რაოდენობის ღილაკები
    Bill.jsx                   → ანგარიშის sidebar
    BillItem.jsx               → ანგარიშის ერთი ხაზი
    ServiceSelector.jsx        → მომსახურების % და ადამიანების რაოდენობა
    CloseBill.jsx              → ანგარიშის დახურვა (async)
    SymptomPanel.jsx           → სიმპტომების სია
```

> **შენიშვნა:** კოდში `console.log`-ები Entry/Exit სტილითაა დატოვებული — ისინი ნავიგაციაში დაგეხმარებათ, მაგრამ **ბაგის მიზეზს არ ამბობენ**. Breakpoint-ები და Scope პანელი გჭირდებათ.
