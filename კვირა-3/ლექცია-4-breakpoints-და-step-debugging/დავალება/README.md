# დავალება: Breakpoints და Step Debugging — Split the Bill

**ლექცია:** კვირა 3, ლექცია 4
**პროექტი:** `homework-breakpoints/`
**შესრულების დრო:** ~2-3 საათი (დამოუკიდებლად)

---

## აღწერა

მოცემულია **Split the Bill** — React აპლიკაცია რესტორნის ანგარიშის დათვლისა და ადამიანებზე გაყოფისთვის. აპი გარეგნულად მუშაობს, მაგრამ **5 ბაგია** ჩადებული — იგივე ტიპის, რაც ლექციის გაიდში (`../GUIDE.md`) `demo-breakpoints` პროექტზე განვიხილეთ, ოღონდ **სხვა დომენში და სხვა კოდში**.

განსხვავება ლექციის პროექტისგან:

- კოდში `// BUG #N` კომენტარები **არ არის**
- გვერდის ბოლოს პანელი მხოლოდ **სიმპტომს** და გამეორების ნაბიჯებს აღწერს
- თითოეული ბაგისთვის **სავალდებულოა კონკრეტული breakpoint-ის ტიპის გამოყენება** (ქვემოთ მითითებულია)

**შენი ამოცანა:** იპოვე 5-ვე ბაგი მითითებული breakpoint-ის ტიპით, გამოასწორე და დაადასტურე შედეგი.

> ⚠️ **მთავარი წესი:** ბაგი „თვალით" კოდის კითხვით რომ იპოვო, ეს დავალება არ ითვლება შესრულებულად. ყოველი ბაგზე უნდა აჩვენო, რომ breakpoint-ით მიხვედი მიზეზამდე (screenshot: Scope / Watch / Call Stack / Console logpoint-ის გამონატანით).

## ნაწილი 3: ბაგი #2 — „+" ღილაკი (Step Into / Step Out)

**სავალდებულო ინსტრუმენტი:** F11 (Step Into) + Shift+F11 (Step Out) + Scope

### ამოცანა

- [ ] მენიუში დააჭირე „+" — რაოდენობა 11 ხდება
- [ ] დასვი breakpoint `MenuCard.jsx` → `handlePlus`-ში
- [ ] **F11**-ით შედი დამხმარე ფუნქციაში (რომელი ფაილში აღმოჩნდი?)

## ნაწილი 6: ბაგი #5 — მომსახურების საფასური (Conditional Breakpoint + Watch)

**სავალდებულო ინსტრუმენტი:** Conditional breakpoint + Watch expressions

### ამოცანა

- [ ] დაამატე კერძები ისე, რომ ქვეჯამი 45.00 ₾ იყოს, აირჩიე 15% — ჩანს 6.00 ₾ (უნდა იყოს 6.75 ₾)
- [ ] `billing.js` → `calculateServiceFee` — დასვი **conditional breakpoint** პირობით:
  ```
  servicePercent === 15 && subtotal > 40
  ```
- [ ] Watch პანელში დაამატე:
  ```
  subtotal * (servicePercent / 100)
  fee
  roundedFee
  ```
- [ ] ჩაწერე მნიშვნელობები: `fee = ___`, `roundedFee = ___`
- [ ] ჩაწერე მიზეზი: რას აკეთებს `parseInt` ათწილადებთან და რითი განსხვავდება `Math.round`-ისგან
- [ ] გამოასწორე ისე, რომ 2 ათწილადი შენარჩუნდეს
- [ ] დაადასტურე: 45.00 × 15% = **6.75 ₾**, ჯამი = **51.75 ₾**

> **კითხვა:** რატომ ჯობია აქ conditional breakpoint ჩვეულებრივს? (რამდენჯერ იძახება ეს ფუნქცია ერთ რენდერზე?)
