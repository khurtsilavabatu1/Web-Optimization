## Breakpoint-ები (მთავარი რესურსები)

- [Pause your code with breakpoints (Chrome DevTools)](https://developer.chrome.com/docs/devtools/javascript/breakpoints) — **მთავარი დოკუმენტაცია**: breakpoint-ის ყველა ტიპი — line-of-code, conditional, logpoint, DOM, XHR, event listener, exception
- [Debug JavaScript (Chrome DevTools)](https://developer.chrome.com/docs/devtools/javascript) — ეტაპობრივი tutorial: პირველი breakpoint-იდან ბაგის გამოსწორებამდე
- [JavaScript debugging reference (Chrome DevTools)](https://developer.chrome.com/docs/devtools/javascript/reference) — სრული ცნობარი: Scope, Watch, Call Stack, step-ის ღილაკები
- [debugger statement (MDN)](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/debugger) — `debugger;` — breakpoint პირდაპირ კოდიდან
