# ლექცია 3 — Sources Panel და Network Panel

## 3.1 Sources Panel

- **რას აკეთებს:** source code-ის ნახვა, breakpoints, step debugging
- **Workspace:** ლოკალური ფაილების binding DevTools-თან
- **Snippets:** ხშირად გამოყენებული scripts-ის შენახვა

### debugger Statement:
```javascript
function processOrder(order) {
  const total = calculateTotal(order.items);
  debugger; // DevTools გახსნილი რომ იყოს, აქ გაჩერდება
  if (total > 1000) {
    applyDiscount(order);
  }
}
```
- დროებით — კონკრეტული პრობლემის debugging-ისთვის
- **ყოველთვის წაშალეთ production კოდიდან!**

## 3.2 Network Panel

- **რას აკეთებს:** ყველა ქსელური მოთხოვნის მონიტორინგი

### ფილტრები: XHR, JS, CSS, Img, Media, Font, Doc, WS

### თითოეული request-ის ინფორმაცია:
- **Headers** — request/response headers
- **Preview** — response ფორმატირებული
- **Response** — raw response
- **Timing** — DNS, Connect, TTFB, Download დროები
- **Initiator** — ვინ გამოიწვია ეს request

### Throttling:
- **Slow 3G** — ნელი მობილური ქსელი
- **Fast 3G** — სწრაფი მობილური ქსელი
- **Offline** — ინტერნეტის გარეშე

### HTTP Status Codes (ხშირად გამოყენებული):
```
200 — OK
201 — Created
400 — Bad Request
401 — Unauthorized
403 — Forbidden
404 — Not Found
500 — Internal Server Error
```

### სავარჯიშო 1: Network Tab
1. გახსენით ნებისმიერი ვებგვერდი
2. Network tab → Disable cache → Reload
3. ჩაწერეთ:
   - რამდენი request გაეშვა?
   - ჯამური ზომა (transferred)?
   - ყველაზე დიდი ფაილი?
   - ყველაზე ნელი request?

### სავარჯიშო 2: API Call
1. Console-ში გაუშვით:
```javascript
fetch('https://jsonplaceholder.typicode.com/posts/1')
  .then(r => r.json())
  .then(data => console.log(data))
```
2. Network tab-ში იპოვეთ ეს request
3. ჩაწერეთ: Status, Content-Type, Response Size, TTFB
