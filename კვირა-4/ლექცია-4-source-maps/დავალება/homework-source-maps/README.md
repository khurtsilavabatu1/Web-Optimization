# Order Desk — Source Maps დავალების პროექტი

**კვირა 4, ლექცია 4 — Source Maps + Debugging Challenge**

ეს არის დავალების პროექტი Vite + React-ზე: შეკვეთების პანელი, კუპონები და გადასახდელის
გამოთვლა. აპლიკაცია შეიცავს **5 განზრახ ჩადებულ ბაგს**, რომლებიც შერჩეულია ლექციის
„გავრცელებული React შეცდომების" სიიდან (`../კონსპექტი.md`, 4.2) და **production build-ზე**
უნდა იპოვოთ:

| ინსტრუმენტი | რას პოულობს |
|---|---|
| `npm run build` + `npm run preview` | რას ხედავს **რეალური მომხმარებელი** (მინიფიცირებული კოდი) |
| **Source Maps** (`sourcemap: true`) | წაუკითხავი stack trace → ორიგინალი ფაილი და ხაზი |
| **React error decoder** | „Minified React error #NNN" → სრული შეტყობინება |
| **Console** (dev vs prod) | გამაფრთხილებლები, რომლებიც production-ში ამოჭრილია |
| `sourcemap: 'hidden'` | .map ფაილი error tracking-ისთვის, მომხმარებლისთვის — არა |

> კოდში `// BUG #N` კომენტარები **არ არის** — ბაგები თავად უნდა იპოვოთ.

## 🚀 გაშვება

**dev რეჟიმი** (სრული warning-ები, source maps ავტომატურად):

```bash
npm install
npm run dev
```

**production build** (ის, რაც სერვერზე წავიდოდა):

```bash
npm run build
npm run preview
```

`npm run preview` ჰოსტავს `dist/` ფოლდერს — ანუ ზუსტად იმ არტეფაქტს, რასაც მომხმარებელი
ჩამოტვირთავს. **ბაგების ძებნა ამ რეჟიმში იწყება.**

## 🔧 Source Maps-ის კონფიგურაცია

ერთადერთი პარამეტრი, რომელსაც დავალების განმავლობაში შეცვლით, `vite.config.js`-შია:

```js
build: {
  sourcemap: false,      // ნაწილი 2 — ასეა თავიდან
  // sourcemap: true,    // ნაწილი 3
  // sourcemap: 'hidden' // ნაწილი 6
}
```

ყოველი ცვლილების შემდეგ: `rm -rf dist && npm run build && npm run preview`.

## 🧪 რატომ არის აქ 5 ბაგი „უცნაურად შერჩეული"

თითოეული ბაგი **სხვანაირად ჩანს** dev და production რეჟიმებში:

| ბაგი | dev რეჟიმი | production build |
|---|---|---|
| TypeError (`toFixed`) | სრული შეტყობინება + ფაილი:ხაზი | სრული შეტყობინება, წაუკითხავი stack |
| ობიექტი როგორც React child | სრული შეტყობინება + კომპონენტების ხე | შეტყობინება არის, კომპონენტი — არა |
| `key` prop-ის გამაფრთხილებელი | ყვითელი warning Console-ში | **საერთოდ არ ჩანს** |
| „Too many re-renders" | სრული ტექსტი | **„Minified React error #NNN"** |
| „Cannot update a component..." | წითელი warning | **საერთოდ არ ჩანს** |

სწორედ ეს განსხვავებაა ამ ლექციის მთავარი თემა.
