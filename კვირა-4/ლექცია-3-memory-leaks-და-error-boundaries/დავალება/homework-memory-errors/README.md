# Live Ops Console — Memory Leaks და Error Boundaries დავალების პროექტი

**კვირა 4, ლექცია 3 — Memory Leaks და Error Boundaries**

ეს არის დავალების პროექტი Vite + React-ზე: სერვერების მონიტორინგის კონსოლი ცალ-ცალკე
ჩართვადი/გამორთვადი ვიჯეტებით. აპლიკაცია შეიცავს **5 memory leak-ს + 1 გატეხილ
Error Boundary-ს** და თითოეული ისე შერჩეულია, რომ **ლექციის კონკრეტული ინსტრუმენტით**
მოიძებნოს:

| ინსტრუმენტი | რას პოულობს |
|---|---|
| **Performance Monitor** → Event Listeners | გაუწმენდავი `addEventListener` |
| **Performance Monitor** → JS Heap Size | უსასრულოდ მზარდი მონაცემები |
| **Performance Monitor** → DOM Nodes | detached DOM ელემენტების დაგროვება |
| **Memory tab** → Heap Snapshot (ფილტრი „Detached") | კონკრეტულად რომელი ელემენტები რჩება |
| **Console** | ტაიმერი, რომელიც unmount-ის შემდეგაც მუშაობს; პასუხების თანმიმდევრობა |
| **Error Boundary** + Console | რას იჭერს boundary და რას — ვერა |

## 🔬 რატომ არის StrictMode გამორთული

`StrictMode` dev რეჟიმში ყოველ effect-ს განზრახ ორჯერ უშვებს
(mount → cleanup → mount ხელახლა) — სწორედ იმისთვის, რომ **გაუწმენდავი** effect-ები
გამოააშკარაოს. ამ დავალებაში ის გამორთულია, რომ leak-ების **დათვლა** (1 ჩართვა =
1 listener / 1 interval) ზუსტი და შედარებადი იყოს.

> **ბონუს სავარჯიშო:** გასწორების შემდეგ `main.jsx`-ში ჩართეთ `StrictMode` და შეამოწმეთ,
> რომ ლოგები წყვილდება (`დაიწყო` → `შეჩერდა` → `დაიწყო`) — ეს cleanup-ის სისწორის ტესტია.
