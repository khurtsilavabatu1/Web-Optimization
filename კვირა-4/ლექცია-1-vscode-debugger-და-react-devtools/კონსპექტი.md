# ლექცია 1 — VS Code Debugger და React DevTools

## 1.1 VS Code Debugger

### რატომ VS Code Debugger?
Chrome DevTools-ისგან განსხვავებით:
- Debug-ი პირდაპირ IDE-ში, კოდის რედაქტირების გვერდით
- Breakpoints-ის შენახვა სესიებს შორის
- Multi-target debugging (frontend + backend ერთდროულად)

### კონფიგურაცია — launch.json:
```json
// .vscode/launch.json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "chrome",
      "request": "launch",
      "name": "React App Debug",
      "url": "http://localhost:5173",
      "webRoot": "${workspaceFolder}/src",
      "sourceMaps": true
    },
    {
      "type": "node",
      "request": "launch",
      "name": "Node Server Debug",
      "program": "${workspaceFolder}/server/index.js"
    }
  ]
}
```

### VS Code Shortcuts:
```
F5          — Start/Continue debugging
F9          — Toggle breakpoint
F10         — Step Over
F11         — Step Into
Shift+F11   — Step Out
Shift+F5    — Stop debugging
```

### VS Code-ის უპირატესობები:
- **Inline Values** — ცვლადის მნიშვნელობა ჩანს პირდაპირ კოდში
- **Debug Console** — expressions-ის evaluation
- **Data Breakpoints** — ცვლადის მნიშვნელობის ცვლილებაზე გაჩერება

## 1.2 React DevTools

### ინსტალაცია:
Chrome Extension: "React Developer Tools" → ამატებს 2 tab-ს:
1. **Components** — კომპონენტების ხე
2. **Profiler** — რენდერინგის ანალიზი

### Components Tab:
- კომპონენტების იერარქია (ხის სახით)
- Props, State, Hooks ინსპექტირება
- State-ის real-time რედაქტირება
- "Rendered by" — ვინ არენდერებს
- **Settings → "Highlight updates when components render"** — ყვითელი border = render

### Profiler Tab:

**როგორ გამოვიყენოთ:**
1. Profiler tab → Record
2. შეასრულეთ მოქმედებები
3. Stop → გაანალიზეთ

**Flamegraph View:**
```
App ████████████████████████████  (15ms)
├── Header ██████                 (3ms)    — სწრაფი
├── ProductList ████████████████  (10ms)   — ნელი!
│   ├── ProductCard ████          (2ms)
│   └── ProductCard ████████      (4ms)
└── Footer ██                     (2ms)
```

**რატომ მოხდა render?**
Settings → "Record why each component rendered":
- Props changed
- State changed
- Parent rendered
- Hooks changed
