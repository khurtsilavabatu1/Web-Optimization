# Playlist Studio — React DevTools დავალების პროექტი

**კვირა 4, ლექცია 1 — VS Code Debugger და React DevTools**

ეს არის დავალების პროექტი Vite + React-ზე: მუსიკის ბიბლიოთეკა, რეკომენდაციები და პლეილისტი.
აპლიკაცია შეიცავს **5 განზრახ ჩადებულ ბაგს + 1 წარმადობის პრობლემას** და თითოეული ისე შერჩეულია,
რომ **ლექციის კონკრეტული ინსტრუმენტით** მოიძებნოს:

| ინსტრუმენტი | რას პოულობს |
|---|---|
| React DevTools → **Components** | props/state/hooks-ის რეალური მნიშვნელობები, არასწორი key |
| Components → **State editing** | ჰიპოთეზის შემოწმება კოდის შეცვლის გარეშე |
| Components → **Highlight updates** | ზედმეტი რენდერების ვიზუალიზაცია |
| React DevTools → **Profiler** | ძვირი კომპონენტი (Ranked) და რენდერის მიზეზი |
| **VS Code Debugger** | breakpoint, VARIABLES, WATCH, Debug Console |

> კოდში `// BUG #N` კომენტარები **არ არის** — ბაგები თავად უნდა იპოვოთ.

## 🚀 გაშვება

```bash
npm install
npm run dev
```

ბრაუზერში: `http://localhost:5173`

VS Code Debugger-ისთვის (F5) **გახსენით სწორედ ეს ფოლდერი** VS Code-ში
(File → Open Folder → `homework-react-devtools`) — `.vscode/launch.json` `${workspaceFolder}`-ს იყენებს.

## 🧩 რას აკეთებს აპლიკაცია

- **რეკომენდაციები** — 10 ტრეკის ბიბლიოთეკა, ძიება სათაურით + ჟანრის ფილტრი
- **ბარათის მოქმედებები** — პლეილისტში დამატება, „დეტალები", 🚫 „არ მომწონს" (სიიდან დამალვა)
- **პლეილისტი** — მწკრივები გამეორებების მთვლელით (`x2`, `x3`), ჯამური დრო, გასუფთავება
- **სტატისტიკა** — საშუალო ხანგრძლივობა, მოსმენები, ტოპ ჟანრი, „audio fingerprint" (მძიმე გამოთვლა)

## 🐛 ბაგები

გვერდის ბოლოს **სიმპტომების პანელია** — 6 ბარათი, თითოეულზე მითითებულია
სავალდებულო ინსტრუმენტი და გამეორების ნაბიჯები. მიზეზი, ფაილი და ხაზი დავალების ნაწილია.

დეტალური ინსტრუქცია და ჩასაბარებელი მასალები: `../README.md`

## 📁 სტრუქტურა

```
src/
  main.jsx                     → entry point (StrictMode გამორთულია)
  App.jsx                      → ბიბლიოთეკა, state და handler-ები
  App.css
  utils/
    playlist.js                → formatDuration, ჯამების დათვლა
    stats.js                   → computeLibraryStats (მძიმე გამოთვლა)
  components/
    FilterBar.jsx              → ძიება + ჟანრის ფილტრი
    TrackList.jsx              → ბარათების grid
    TrackCard.jsx              → ცალკეული ტრეკი (ლოკალური state — „დეტალები")
    PlaylistPanel.jsx          → პლეილისტი და ჯამები
    StatsFooter.jsx            → სტატისტიკა (ძვირი კომპონენტი)
    SymptomPanel.jsx           → სიმპტომების სია (ეს ფაილი არ არის ბაგიანი)
```
