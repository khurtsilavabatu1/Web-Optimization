## 3.1 Babel — JavaScript Transpiler

```javascript
// Modern JavaScript (ES2024)
const result = data?.items?.map(item => item.name) ?? [];

// Babel output (ES5-თავსებადი)
var _data, _data$items;
var result = (_data = data) !== null && _data !== void 0 
  && (_data$items = _data.items) !== null && _data$items !== void 0 
  ? _data$items.map(function(item) { return item.name; }) 
  : [];
```

## 3.2 Polyfills

```javascript
// Polyfill = ახალი API-ის იმპლემენტაცია ძველი ბრაუზერისთვის

// მაგალითი: Array.prototype.at()
if (!Array.prototype.at) {
  Array.prototype.at = function(index) {
    if (index < 0) index = this.length + index;
    return this[index];
  };
}

// core-js — ყველაზე პოპულარული polyfills კოლექცია
// useBuiltIns: "usage" — მხოლოდ საჭიროს ჩასვამს
```

## 3.4 Progressive Enhancement vs Graceful Degradation

### Progressive Enhancement:
ძირითადი ფუნქციონალურობით დაიწყე, გააუმჯობესე თანამედროვე ბრაუზერებისთვის.

```html
<form action="/search" method="GET">
  <input type="text" name="q">
  <button type="submit">ძებნა</button>
</form>

<script>
if ('fetch' in window) {
  document.querySelector('form').addEventListener('submit', async (e) => {
    e.preventDefault();
    const results = await fetch(`/api/search?q=${e.target.q.value}`).then(r => r.json());
    renderResults(results);
  });
}
</script>
```

### Graceful Degradation:
თანამედროვეთი დაიწყე, fallback-ები გქონდეს ძველი ბრაუზერებისთვის.

```css
.layout { display: grid; grid-template-columns: repeat(auto-fit, minmax(300px, 1fr)); gap: 20px; }

@supports not (display: grid) {
  .layout { display: flex; flex-wrap: wrap; }
  .layout > * { flex: 0 0 calc(33.333% - 20px); margin: 10px; }
}
```
