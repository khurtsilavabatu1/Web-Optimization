# ლექცია 1 — ბრაუზერების განსხვავებები და caniuse

## 1.1 ბრაუზერების რენდერინგის ძრავები

| ბრაუზერი | Rendering Engine | JavaScript Engine | Market Share |
|----------|-----------------|-------------------|-------------|
| Chrome | Blink | V8 | ~65% |
| Safari | WebKit | JavaScriptCore | ~18% |
| Firefox | Gecko | SpiderMonkey | ~3% |
| Edge | Blink (Chromium) | V8 | ~5% |

### რატომ არის მნიშვნელოვანი?
- სხვადასხვა ძრავა სხვადასხვანაირად ინტერპრეტირებს CSS/JS-ს
- ახალი ფუნქციები სხვადასხვა დროს ჩნდება
- Safari ხშირად ჩამორჩება ახალი Web API-ების მხარდაჭერაში
- მობილური ბრაუზერები დამატებით გამოწვევებს ქმნიან

### პრობლემური სფეროები:

**CSS-ში:**
- Flexbox gap (ძველი Safari)
- `backdrop-filter` (prefix)
- `:has()` selector (ახალი)
- `100vh` iOS Safari-ში

**JavaScript-ში:**
- Optional chaining (`?.`) — ძველი ბრაუზერები
- `structuredClone()` — ახალი API
- `ResizeObserver`, `IntersectionObserver` — ნაწილობრივი

## 1.2 caniuse.com

### რა არის?
caniuse.com — CSS/JS/HTML ფუნქციების მხარდაჭერის მონაცემთა ბაზა.

### პრაქტიკული გამოყენება:
1. მოძებნეთ ფუნქცია (მაგ. "container queries")
2. ნახეთ მხარდაჭერის პროცენტი
3. გადაწყვიტეთ — fallback სჭირდება თუ არა

## 1.3 Browserslist

```json
// package.json
{
  "browserslist": [
    "> 0.5%",
    "last 2 versions",
    "not dead",
    "not ie 11"
  ]
}
```

**ვინ იყენებს:**
- **Babel** — JS transpilation
- **Autoprefixer** — CSS prefixes
- **PostCSS** — CSS transformation

```bash
# რომელ ბრაუზერებს მოიცავს?
npx browserslist
```
