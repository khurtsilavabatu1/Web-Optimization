# ლექცია 2 — CSS თავსებადობა

## 2.1 Vendor Prefixes

```css
/* ❌ ხელით (არ არის რეკომენდებული) */
.element {
  -webkit-backdrop-filter: blur(10px);
  backdrop-filter: blur(10px);
  -webkit-user-select: none;
  -moz-user-select: none;
  user-select: none;
}

/* ✅ Autoprefixer — ავტომატურად */
/* Input: */
.element {
  backdrop-filter: blur(10px);
  user-select: none;
}
/* Autoprefixer output: პრეფიქსები ავტომატურად დაემატება */
```

### Autoprefixer კონფიგურაცია:
```javascript
// postcss.config.js
module.exports = {
  plugins: [require('autoprefixer')],
};
// Vite-ში ავტომატურად ჩართულია
```

## 2.2 @supports — Feature Queries

```css
/* Fallback */
.container {
  display: flex;
  flex-wrap: wrap;
}

/* გაუმჯობესება — თუ grid მხარდაჭერილია */
@supports (display: grid) {
  .container {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: 20px;
  }
}

/* Container queries */
@supports (container-type: inline-size) {
  .card-container {
    container-type: inline-size;
  }
}
```

## 2.3 CSS Reset / Normalize

```css
/* Modern CSS Reset */
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

  -moz-text-size-adjust: none;

  text-size-adjust: none;
}

  display: block;
  max-width: 100%;

input, button, textarea, select {
  font: inherit;
}
```

## 2.4 ხშირი CSS პრობლემები

### Flexbox gap Safari-ში:
```css
/* ❌ Safari 14-ში არ მუშაობს */
.flex { display: flex; gap: 16px; }

/* ✅ Fallback */
.flex > * + * { margin-left: 16px; }
@supports (gap: 16px) {
  .flex { gap: 16px; }
  .flex > * + * { margin-left: 0; }
}
```

### iOS Safari 100vh:
```css
.full-height {
  height: 100vh;    /* ძველი */
  height: 100dvh;   /* ახალი — dynamic viewport height */
}
```

### Scrollbar სტილიზაცია:
```css
/* Chrome/Edge */
::-webkit-scrollbar { width: 8px; }
::-webkit-scrollbar-thumb { background: #888; border-radius: 4px; }

/* Firefox */
* {
  scrollbar-width: thin;
  scrollbar-color: #888 #f1f1f1;
}
```
