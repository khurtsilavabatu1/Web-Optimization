# ლექცია 2 — CSS თავსებადობა

## 2.1 Vendor Prefixes

```css
/* ❌ ხელით (არ არის რეკომენდებული) */
.element {
  -webkit-backdrop-filter: blur(10px);
  backdrop-filter: blur(10px);
  -webkit-user-select: none;
  -moz-user-select: none;
  user-select: none;
}

/* ✅ Autoprefixer — ავტომატურად */
/* Input: */
.element {
  backdrop-filter: blur(10px);
  user-select: none;
}
/* Autoprefixer output: პრეფიქსები ავტომატურად დაემატება */
```

### Autoprefixer კონფიგურაცია:

```bash
npm install -D autoprefixer postcss
```

```javascript
// postcss.config.js  (პროექტის ფესვში)
import autoprefixer from 'autoprefixer'

export default {
  plugins: [autoprefixer()],
}
```

```json
// package.json — ეს წყვეტს, რომელი prefix დაემატება
{
  "browserslist": ["> 0.2%", "last 4 versions", "Safari >= 12", "not dead"]
}
```

> ⚠️ **Autoprefixer Vite-ს თან არ მოყვება.** Vite CSS-ს PostCSS-ით ამუშავებს —
> ანუ `postcss` `node_modules`-ში ისედაც გიდევს — მაგრამ **Autoprefixer ცალკე
> უნდა დააყენო** და `postcss.config.js` შენ უნდა შექმნა. ავტომატურია მხოლოდ ის,
> რომ Vite ამ ფაილს თავად აღმოაჩენს.

> 💡 `npx browserslist` — ნახავ, ზუსტად რომელი ბრაუზერები მოხვდა სიაში.
> სია რაც უფრო ვიწროა, მით ნაკლები prefix დაემატება (შესაძლოა — არცერთი).

### რას *არ* ამატებს Autoprefixer:
- `::-webkit-scrollbar`, `::-moz-range-thumb` — ბრაუზერის საკუთარი pseudo-element-ები
- `-webkit-text-fill-color` — WebKit-ის საკუთარი property, არა prefix
- polyfill-ებს — მხოლოდ სინტაქსს ეხება, არა ფუნქციონალს

## 2.2 @supports — Feature Queries

```css
/* Fallback */
.container {
  display: flex;
  flex-wrap: wrap;
}

/* გაუმჯობესება — თუ grid მხარდაჭერილია */
@supports (display: grid) {
  .container {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: 20px;
  }
}

/* Container queries */
@supports (container-type: inline-size) {
  .card-container {
    container-type: inline-size;
  }
}
```

## 2.3 CSS Reset / Normalize

```css
/* Modern CSS Reset */
*, *::before, *::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

html {
  -moz-text-size-adjust: none;
  -webkit-text-size-adjust: none;
  text-size-adjust: none;
}

img, picture, video, canvas, svg {
  display: block;
  max-width: 100%;
}

input, button, textarea, select {
  font: inherit;
}
```

## 2.4 ხშირი CSS პრობლემები

### Flexbox gap Safari-ში:
```css
/* ❌ Safari 14-ში არ მუშაობს */
.flex { display: flex; gap: 16px; }

/* ✅ Fallback */
.flex > * + * { margin-left: 16px; }
@supports (gap: 16px) {
  .flex { gap: 16px; }
  .flex > * + * { margin-left: 0; }
}
```

### iOS Safari 100vh:
```css
.full-height {
  height: 100vh;    /* ძველი */
  height: 100dvh;   /* ახალი — dynamic viewport height */
}
```

### Scrollbar სტილიზაცია:
```css
/* Chrome/Edge */
::-webkit-scrollbar { width: 8px; }
::-webkit-scrollbar-thumb { background: #888; border-radius: 4px; }

/* Firefox */
* {
  scrollbar-width: thin;
  scrollbar-color: #888 #f1f1f1;
}
```

### დემოზე გასაშვები (`demo-css-compatibility/`)

```bash
npm install
npm run prefixes    # სია: რომელ ფაილს რა prefix დაემატა
npm run build       # dist/assets/*.css — უკვე prefix-ებიანი შედეგი
```

შემდეგ `package.json`-ში `browserslist` შეცვალე `["last 1 chrome version"]`-ით
და ისევ გაუშვი `npm run prefixes` — prefix-ები გაქრება. ეს არის მთავარი დასკვნა:
**output-ს browserslist წყვეტს, არა Autoprefixer.**
