# ლექცია 3 — PageSpeed Insights და WebPageTest

## 3.1 Google PageSpeed Insights

### რა არის?
PageSpeed Insights (PSI) არის Google-ის ონლაინ ინსტრუმენტი, რომელიც აერთიანებს:
- **Lab Data:** Lighthouse-ის ანალიზი (სიმულირებული)
- **Field Data:** Chrome User Experience Report (CrUX) — რეალური მომხმარებლების მონაცემები

### Lighthouse vs PageSpeed Insights:

| თვისება | Lighthouse | PageSpeed Insights |
|---------|-----------|-------------------|
| მონაცემები | Lab only | Lab + Field |
| გაშვება | ლოკალურად/CI | ონლაინ |
| რეალური მომხმარებლები | არა | დიახ (CrUX) |
| localhost | დიახ | არა |
| კონფიგურაცია | მოქნილი | შეზღუდული |

### გამოყენება:
1. გახსენით https://pagespeed.web.dev
2. შეიყვანეთ URL
3. აირჩიეთ Mobile ან Desktop
4. გაანალიზეთ შედეგები

### PSI ანგარიშის სექციები:
- **Core Web Vitals Assessment:** Pass/Fail რეალური მონაცემების მიხედვით
- **Lab Data:** Lighthouse-ის მეტრიკები
- **Opportunities:** კონკრეტული რეკომენდაციები (დაზოგილი დროის მითითებით)
- **Diagnostics:** დამატებითი ტექნიკური ინფორმაცია

### React/JavaScript პროექტებში PSI-ის მნიშვნელობა:
- SPA (Single Page Application) აპლიკაციებში ხშირად დიდია JavaScript bundle
- Client-side rendering ზრდის LCP-ს და TBT-ს
- PSI გვეხმარება გავიგოთ, საჭიროა თუ არა SSR/SSG

## 3.2 WebPageTest

### რა არის?
WebPageTest (webpagetest.org) არის ყველაზე დეტალური და ძლიერი უფასო ინსტრუმენტი ვებ წარმადობის ტესტირებისთვის.

### უპირატესობები Lighthouse-თან შედარებით:
- **რეალური ბრაუზერები** სხვადასხვა გეოგრაფიულ ლოკაციიდან
- **Waterfall Chart** — თითოეული რესურსის ჩატვირთვის დეტალური ვიზუალიზაცია
- **Filmstrip View** — გვერდის ჩატვირთვის პროცესის კადრ-კადრ ჩვენება
- **Connection Throttling** — რეალური ქსელის პირობების სიმულაცია
- **Comparison** — ორი URL-ის შედარება

### გამოყენება:
1. გახსენით https://www.webpagetest.org
2. შეიყვანეთ URL
3. აირჩიეთ ლოკაცია (მაგ. Europe — London)
4. აირჩიეთ ბრაუზერი
5. Advanced Settings-ში დააკონფიგურირეთ connection speed

### Waterfall Chart-ის კითხვა:
```
DNS Lookup    ██                    → დომენის IP-ზე resolve
TCP Connect      ██                → TCP კავშირის დამყარება
TLS/SSL             ███            → უსაფრთხო კავშირი
TTFB                    ████       → სერვერის პასუხის მოლოდინი
Content Download            ██████ → კონტენტის გადმოწერა
```

- **ლურჯი ხაზები:** JavaScript ფაილები
- **მწვანე ხაზები:** CSS ფაილები
- **იისფერი ხაზები:** სურათები
- **წითელი ხაზი:** HTML დოკუმენტი

### რა უნდა ვეძებოთ Waterfall-ში:
1. **Render-blocking რესურსები** — CSS/JS რომლებიც აჩერებენ რენდერინგს
2. **Long TTFB** — სერვერის ნელი პასუხი
3. **Large files** — ზედმეტად დიდი ფაილები
4. **Too many requests** — ზედმეტი HTTP მოთხოვნები
5. **No compression** — შეკუმშვის გარეშე გაგზავნილი ფაილები

### 3 ინსტრუმენტის შედარება:

| თვისება | Lighthouse | PSI | WebPageTest |
|---------|-----------|-----|-------------|
| უფასო | ✅ | ✅ | ✅ |
| Real browsers | ❌ | ❌ | ✅ |
| Field data | ❌ | ✅ | ❌ |
| Geo locations | ❌ | ❌ | ✅ |
| Waterfall | ❌ | ❌ | ✅ |
