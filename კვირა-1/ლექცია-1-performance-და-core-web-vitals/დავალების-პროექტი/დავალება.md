## კონტექსტი

მოცემული გაქვთ `დავალების-პროექტი/` ფოლდერში არსებული ვებგვერდი — **TravelGeorgia**, ტურისტული საიტი საქართველოს შესახებ.

## მოსალოდნელი შედეგები

ოპტიმიზაციის შემდეგ:
- Long Tasks: 8-10 → 0-1
- TBT: 2000ms+ → <200ms
- CLS: 0.2+ → <0.05
- LCP: 4s+ → <2s
- სქროლი: janky → smooth (60fps)
- ძებნა: 200ms+ delay → instant
