# ლექცია 2 — მინიმიზაცია და კომპრესია

## 2.1 რესურსების მინიმიზაცია (Minification)

### რა არის?
Minification — კოდიდან ზედმეტი სიმბოლოების მოშორება (spaces, comments, long variable names) ფუნქციონალურობის შეცვლის გარეშე.

### JavaScript Minification:
```javascript
// წყარო (1.2KB)
function calculateTotalPrice(items, taxRate) {
  // გამოვთვალოთ ჯამური ფასი
  let total = 0;
  for (let i = 0; i < items.length; i++) {
    const item = items[i];
    total += item.price * item.quantity;
  }
  const tax = total * taxRate;
  return total + tax;
}

// Minified (320B) — Terser-ის შედეგი
function calculateTotalPrice(t,e){let l=0;for(let a=0;a<t.length;a++){const n=t[a];l+=n.price*n.quantity}return l+l*e}
```

### ინსტრუმენტები:
| ინსტრუმენტი | ენა | სიჩქარე | გამოყენება |
|------------|-----|---------|----------|
| Terser | JS | საშუალო | webpack default |
| esbuild | Go | ძალიან სწრაფი | Vite default |
| SWC | Rust | სწრაფი | Next.js default |
| cssnano | PostCSS | საშუალო | CSS minification |
| Lightning CSS | Rust | ძალიან სწრაფი | Vite ახალი ვერსიები |

### Build Tools-ში:
```javascript
// vite.config.js
export default {
  build: {
    minify: 'terser', // ან 'esbuild' (default, უფრო სწრაფი)
    terserOptions: {
      compress: {
        drop_console: true, // console.log-ების მოშორება production-ში
      },
    },
  },
};
```

## 2.2 კომპრესია (Compression)

### რა არის?
კომპრესია ამცირებს ფაილის ზომას ქსელში გადაცემამდე. სერვერი აკუმშავს, ბრაუზერი ხსნის.

### Gzip vs Brotli:

| თვისება | Gzip | Brotli |
|---------|------|--------|
| შეკუმშვის ხარისხი | კარგი | უკეთესი (20-30% მეტი) |
| სიჩქარე (compress) | სწრაფი | ნელი (static-ისთვის OK) |
| სიჩქარე (decompress) | სწრაფი | სწრაფი |
| ბრაუზერის მხარდაჭერა | ყველა | თანამედროვე ყველა |
| HTTP Header | Content-Encoding: gzip | Content-Encoding: br |

### როგორ ვნახოთ DevTools-ში:
Network tab → Response Headers:
```
Content-Encoding: br    ← Brotli გამოიყენება
Content-Length: 45230    ← შეკუმშული ზომა
```

### რეალური ზომის შედარება (ტიპიური React აპი):
```
Original:    450 KB
Minified:    180 KB  (60% reduction)
Gzipped:      55 KB  (88% reduction)
Brotli:       45 KB  (90% reduction)
```

### სერვერის კონფიგურაცია (Nginx):
```nginx
gzip on;
gzip_types text/plain text/css application/json application/javascript;
gzip_min_length 1000;
```

## სავარჯიშო

1. შექმენით React პროექტი, დაამატეთ: `npm install lodash moment chart.js`
2. გამოიყენეთ თითოეულიდან ერთი ფუნქცია
3. `npm run build` — ჩაინიშნეთ bundle ზომა
4. შეცვალეთ `lodash` → `lodash-es`, `moment` → `date-fns`
5. ხელახლა build — რამდენით შემცირდა?
6. Network tab-ში ნახეთ: ფაილები Gzip/Brotli-თ იგზავნება?
