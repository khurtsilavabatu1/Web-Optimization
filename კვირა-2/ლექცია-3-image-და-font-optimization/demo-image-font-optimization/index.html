Responsive Images — srcset + sizes

ეს სურათი სხვადასხვა ზომის ვერსიებს იყენებს. DevTools-ში viewport-ის ზომა შეცვალეთ და Network tab-ში დააკვირდით რომელი ვერსია ჩაიტვირთება.

როგორ შევამოწმოთ:
  1. DevTools → Network tab → "Img" ფილტრი
  2. Device Toolbar ჩართეთ (Cmd+Shift+M)
  3. სხვადასხვა viewport ზომაზე გადატვირთეთ (hard refresh: Cmd+Shift+R)
  4. ნახეთ რომელი ფაილი ჩაიტვირთა (400w, 800w თუ 1200w)

Font Display — 4 ვარიანტი

ქვემოთ იგივე ტექსტი 4 სხვადასხვა font-display მნიშვნელობით ჩანს. Network tab-ში ფონტების ჩატვირთვა შეაჩერეთ (Slow 3G) და განსხვავება დააკვირდით.

როგორ შევამოწმოთ font-display:
  1. DevTools → Network tab → "Font" ფილტრი
  2. Network throttling: "Slow 3G" აირჩიეთ
  3. Hard refresh (Cmd+Shift+R)
  4. დააკვირდით ტექსტის ქცევას ფონტის ჩატვირთვამდე

font-display: block

ეს ტექსტი უხილავია ფონტის ჩატვირთვამდე. ბრაუზერი ელოდება custom ფონტს და მანამდე ტექსტი საერთოდ არ ჩანს (FOIT — Flash of Invisible Text).

block

font-display: swap

ეს ტექსტი მაშინვე ჩანს სისტემური ფონტით, შემდეგ იცვლება custom ფონტზე. ეს არის რეკომენდებული ვარიანტი (FOUT — Flash of Unstyled Text).

swap (recommended)

font-display: fallback

მოკლე ხანს ელოდება, შემდეგ სისტემურ ფონტს აჩვენებს. თუ custom ფონტი რამდენიმე წამში არ ჩაიტვირთა, სისტემურზე რჩება.

fallback

font-display: optional

თუ ფონტი ძალიან სწრაფად ჩაიტვირთა (მაგ. ქეშში იყო), იყენებს. თუ არა — სისტემურს ტოვებს. ყველაზე მკაცრი performance-ის კუთხით.

optional

Self-hosted Font vs Google Fonts CDN

Self-hosted (ლოკალური)

ეს ტექსტი self-hosted Inter ფონტით ჩანს. ფონტის ფაილი პროექტშია (fonts/ ფოლდერში). ბრაუზერს Google-ის სერვერთან დაკავშირება არ სჭირდება.

self-hosted

Google Fonts CDN

ეს ტექსტი Google Fonts CDN-ით ჩაიტვირთა. ბრაუზერი ჯერ Google-ის სერვერთან კავშირს ამყარებს, CSS-ს ტვირთავს, შემდეგ ფონტის ფაილს.

CDN
Network tab-ში შეადარეთ:
  1. Self-hosted: ერთი request ლოკალური ფაილისთვის
  2. CDN: fonts.googleapis.com + fonts.gstatic.com — ორი სხვადასხვა სერვერის request
