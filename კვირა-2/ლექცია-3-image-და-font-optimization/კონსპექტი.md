# ლექცია 3 — გამოსახულების და ფონტების ოპტიმიზაცია

## 3.1 გამოსახულების ოპტიმიზაცია

### რატომ არის მნიშვნელოვანი?
- სურათები ტიპიურად **50-70%** შეადგენს ვებგვერდის მთლიანი წონისას
- არაოპტიმიზირებული სურათი: 2-5MB, ოპტიმიზირებული: 50-200KB

### ფორმატების შედარება:

| ფორმატი | გამოყენება | ზომა | ხარისხი | მხარდაჭერა |
|---------|----------|------|---------|------------|
| JPEG | ფოტოები | საშუალო | კარგი | ყველა |
| PNG | გამჭვირვალე, ტექსტი | დიდი | ძალიან კარგი | ყველა |
| WebP | ყველაფერი | მცირე (-25-35%) | ძალიან კარგი | 97%+ |
| AVIF | ყველაფერი | ყველაზე მცირე (-50%) | საუკეთესო | 92%+ |
| SVG | იკონები, ილუსტრაციები | ძალიან მცირე | სკალირებადი | ყველა |

### HTML-ში ოპტიმალური სურათი:
```html
<!-- picture ელემენტით — ბრაუზერი აირჩევს საუკეთესოს -->
<picture>
  <source srcset="photo.avif" type="image/avif">
  <source srcset="photo.webp" type="image/webp">
  <img src="photo.jpg" alt="აღწერა" width="800" height="600" loading="lazy">
</picture>
```

### Lazy Loading:
```html
<!-- Native lazy loading -->
<img src="photo.jpg" alt="..." loading="lazy" width="400" height="300">

<!-- Above the fold — არ გამოიყენოთ lazy! -->
<img src="hero.jpg" alt="..." loading="eager" fetchpriority="high">
```

### Responsive Images:
```html
<img 
  srcset="image-400w.jpg 400w, image-800w.jpg 800w, image-1200w.jpg 1200w"
  sizes="(max-width: 600px) 100vw, (max-width: 1024px) 50vw, 33vw"
  src="image-800w.jpg"
  alt="აღწერა"
>
```

### React-ში (Next.js Image):
```jsx
import Image from 'next/image';

<Image src="/hero.jpg" alt="Hero" width={1200} height={600} priority />
<Image src="/photo.jpg" alt="Photo" sizes="(max-width: 768px) 100vw, 50vw" fill style={{ objectFit: 'cover' }} />
```

## 3.2 ფონტების ოპტიმიზაცია

### font-display:
```css
@font-face {
  font-family: 'CustomFont';
  src: url('/fonts/custom.woff2') format('woff2');
  font-display: swap; /* ტექსტი მაშინვე ჩანს system font-ით, შემდეგ იცვლება */
}
```

| font-display | ქცევა |
|-------------|-------|
| block | ტექსტი უხილავია ფონტის ჩატვირთვამდე (FOIT) |
| swap | system font → custom font (FOUT) — **რეკომენდებული** |
| fallback | მოკლე block, შემდეგ fallback |
| optional | ფონტი ჩაიტვირთება თუ სწრაფია, თუ არა — system font |

### WOFF2 ფორმატი:
- ყოველთვის გამოიყენეთ WOFF2 — 30% უფრო მცირეა WOFF-ზე
- 97%+ ბრაუზერების მხარდაჭერა

### Google Fonts ოპტიმიზაცია:
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap" rel="stylesheet">
```
